# Versión estática original (legado)

Esta carpeta guarda la primera versión de la calculadora, hecha en HTML, CSS y JavaScript puro
con `localStorage` y exportación a PDF (jsPDF). Se conserva como referencia histórica; la
aplicación actual es el backend en `backend/` (Spring Boot) y el frontend en `frontend/` (Angular).

Para abrirla basta con abrir `legacy/index.html` en el navegador.
